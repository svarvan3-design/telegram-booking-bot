# Telegram-бот записи клиентов

Демо-проект для портфолио: бот онлайн-записи для стоматологии «Белый Квартал» (клиника вымышлена). Легко адаптируется под салон, барбершоп, автосервис, репетитора — меняются только услуги в `storage.py`.

## Что умеет
- **Запись за минуту:** услуга → день (ближайшие 7) → свободное время → имя → телефон (кнопкой или текстом) → подтверждение.
- **Без двойных записей:** занятый слот исчезает из выбора; если двое жмут одновременно, второму предложат другое время.
- **Клиенту:** «Мои записи» с отменой, цены, контакты, напоминание за сутки до визита.
- **Администратору:** уведомление о каждой новой записи и отмене, команды `/today` и `/tomorrow` — расписание на день.
- Данные хранятся в SQLite (`bookings.db`), без внешних сервисов и платных API.

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`.
4. `pip install aiogram` (проверено на aiogram 3.31, Python 3.14)
5. `python bot.py`

Проверка логики без Telegram: `python test_storage.py`

## Настройка под клиента
- Услуги, цены, длительность — словарь `SERVICES` в `storage.py`.
- Рабочие часы и шаг сетки — `WORK_START`, `WORK_END`, `SLOT_MIN`.
- Название, адрес, телефон — в `.env`.
